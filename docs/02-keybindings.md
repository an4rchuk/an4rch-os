# Key bindings

Generated from `default/hypr/binds.lua`. Press <kbd>SUPER</kbd> + <kbd>/</kbd> for a searchable version on your desktop.

The modifiers follow one pattern: <kbd>SUPER</kbd> alone for apps and windows, <kbd>SHIFT</kbd> to move or capture, <kbd>CTRL</kbd> for system toggles and style, <kbd>ALT</kbd> for setup panels.

## Resize mode

<kbd>SUPER</kbd> + <kbd>R</kbd> enters resize mode: arrows or <kbd>H</kbd> <kbd>J</kbd> <kbd>K</kbd> <kbd>L</kbd> resize the window, <kbd>Esc</kbd> or <kbd>Enter</kbd> leaves.
