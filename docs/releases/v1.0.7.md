### Installing without internet
- **Lumen OS now installs with no internet at all**, entirely from the USB stick. Before, an install without Wi-Fi or a cable stopped part-way: it tried to refresh the online package lists, then checked package signatures against keys it could only fetch online, and then the desktop step refused to start without a connection. All three are fixed; the stick's packages are checked when the ISO is built. With internet, nothing changes (mirrors are picked, signatures checked as usual).
- When there's no internet, the installer says so and skips picking the fastest mirrors.

### Alongside Windows
- **Smaller free space is handled instead of refused**: asking for less than 30 GB for Lumen uses 30 GB; asking for more than there's room for uses all the room there is (both with a note). If Windows leaves less than 30 GB, the installer says so clearly before touching the disk.

### Desktop
- **The top bar and taskbar come back by themselves if they crash** (within about 10 seconds), instead of being gone until the next login. Restarts are noted in `lumen doctor`.
- **Chromium, Brave and Google Chrome run as native Wayland apps** (sharper on scaled screens, with proper window decorations).
- The list of apps that couldn't start (`lumen doctor`) no longer fills up with background helpers that stop on their own outside the desktop.

### Testing
- Every release now goes through 19 different virtual machines: low-spec and high-spec, NVIDIA (normal and LTS kernel), dual boot with Windows (encrypted, LTS, small disk, gaming), a UK laptop, a fully encrypted disk, an offline install with a German keyboard, Chromium and Brave as the browser, no taskbar, other terminals and themes, a light theme, a 4K screen, a tiny 2-CPU / 3 GB PC and old BIOS computers.

Existing installs get the desktop fixes with `lumen update`.
