### The an4rch look: red and black
- **A new boot screen.** The an4rch logo starts large in the middle of the screen, shrinks into place as the computer starts, and a red glow settles behind it. The disk password (on encrypted installs) is asked for right under it.
- **The signature an4rch theme is now red and black**, to match the logo: the accent, borders, menus, wallpapers, icons, the USB's boot menu and its splash. The previous violet look lives on as the **an4rch-violet** theme.

### One-step login
- A new login screen that carries on from the boot screen: the logo stays where it was, the clock sits above it, your name is filled in, and you only type the password and press <kbd>Enter</kbd>.
- Pick a session (the desktop or Steam's Game Mode) and restart or shut down from the same screen.
- `anarch login wallpaper on` shows your wallpaper behind it.

### The an4rch Hub
- **Settings is now the an4rch Hub**: one window for everything, with new pages for **Privacy and safety**, **Backups**, **Phone**, **Accessibility**, **Screen time** and **Hardware and drivers**, and **Report a problem** under System. `anarch hub` opens it.

### New features
- **Display scaling that fits the screen**: 4K monitors and sharp laptop panels are scaled at login (150%, 160% or 200%) so text is a comfortable size. Displays you set up yourself keep your choice.
- **Backups (`anarch backup`)**: Time Machine for an4rch. Your home folder, encrypted, every hour to a USB drive or a folder, with versions kept for a year. Restore any file into `~/Restored` without overwriting anything.
- **Phone link (`anarch phone`)**: KDE Connect set up in one command: notifications, files both ways (also from Files' right-click menu), a shared clipboard, ring your phone to find it.
- **Graphics drivers (`anarch drivers`)**: the right NVIDIA driver for each card (open modules, 580 or 470 legacy, or nouveau), `prime-run` on laptops with two graphics chips, and a hint in `anarch doctor` when a better driver is available. The installer no longer puts the new driver on cards it doesn't support.
- **Secure Boot (`anarch secureboot`)**: sign an4rch with your own keys so Secure Boot can stay on, for anti-cheat games and work laptops. Kernel updates sign themselves.
- **Problem reports (`anarch report`)**: everything needed to fix a bug in one file, with your names, addresses and Wi-Fi networks removed, and a new GitHub issue opened to attach it to.
- **Automatic recovery**: after a kernel update the boot menu falls back to a working entry if an4rch doesn't start three times, and if the desktop crashes twice in a row right after logging in, the login screen offers **Undo update**.
- **The Game edition**: a new choice in the installer that starts straight into Steam's Big Picture, like a Steam Deck. Steam → Power → *Switch to Desktop* goes to the login screen. On any install: `anarch gaming game-mode boot on`.

See the manual's new chapter, [The Hub, backups and getting help](../13-hub-backups-and-help.md).

Existing installs get all of this with `anarch update`.
