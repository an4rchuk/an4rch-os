### Chromebooks
- **The keyboard's top row works**: back, forward, refresh, fullscreen, overview (opens Start), brightness and volume, read from each Chromebook's own key layout. **Search + top row** gives F1–F12 and **Search + Backspace** is Delete.
- **The touchpad (and touchscreen) drivers load** on the live USB and after installing.
- (Lumen needs a Chromebook with UEFI firmware, e.g. MrChromebox's, to start at all.)

### Fixes
- Wi-Fi panel: saved networks whose saved name differs from the network's name (e.g. "Home 1") connect without asking for the password again.
- Wi-Fi and Bluetooth panels no longer stack up background refreshes on slow devices.
- About, `lumen doctor` and the system information show the real Lumen OS version (e.g. 1.0.10).

### Testing
- A "brutal" set of 20 extra virtual machines: 1 CPU / 2 GB, 800×600, ultrawide, offline installs with encryption / dual boot / old BIOS / gaming, French, Spanish, Japanese, Swiss and Dvorak keyboards, tiny and huge dual-boot sizes, gaming with NVIDIA and the LTS kernel, every theme and terminal, 8 CPUs / 16 GB.

Existing installs get these with `lumen update`.
