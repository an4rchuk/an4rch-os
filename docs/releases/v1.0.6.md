### Live USB
- **Reaches the desktop on real laptops.** The live desktop had 45 seconds to start before the text installer took over; from a USB stick (USB 2 above all) loading it the first time can take longer, so laptops kept landing in the text installer. Now it gets 4 minutes, shows "Starting the desktop…" instead of a black screen, tries a second, simpler way if the first fails, and then lets you choose (desktop again, text installer, restart) instead of switching by itself.
- **Desktop icons**: "Install Lumen OS" and "Welcome" on the desktop, like other live USBs.
- **No more locked-out live desktop**: after 5 idle minutes the live desktop locked itself and couldn't be unlocked (the live user has no password). It no longer locks or sleeps, and a manual lock unlocks with Enter.
- App preloading waits for the desktop instead of slowing its start.

### Apps
- **Apps never fail silently.** A missing app says so; if the chosen browser isn't installed, another installed browser opens (with a notice); if an app crashes on start, a notification says why; if the system can't start an app the usual way, it starts it directly.
- `lumen doctor` lists apps that couldn't start recently.
- **Task Manager** on **Ctrl + Shift + Esc** (like Windows), a **Text Editor** and a **Camera** app.
- **Extras** (Lumen menu → Extras): phone link (KDE Connect), LocalSend (AirDrop-style sharing), Backups (Déjà Dup), LibreOffice.

### Keyboard, touchpad and laptop keys
- **The keyboard layout chosen in the installer now applies to the desktop and the login screen**, not only the console (UK keyboards had @, ", £ and # in the wrong places). On the live USB the layout switches as soon as you pick it, so passwords type the same after installing.
- Laptop keys: **touchpad on/off**, **keyboard light** (step / off), **display/projector**, **lock**, **sleep**, **browser**, **file manager**, **search**, **settings**, **stop**.

### Wi-Fi
- **School and work Wi-Fi (eduroam and other WPA2/3-Enterprise networks)** asks for a username and password and connects (it used to ask only for a password and fail).
- **Hidden networks** can be joined from the Wi-Fi menu.
- A saved network whose **password changed** is updated instead of a second copy being added.

### Installing
- **Time zone without internet**: follows the keyboard layout (UK → London) instead of UTC, which put the clock an hour out in summer; the installer says when it couldn't detect it.
- Dual boot: how to get the Lumen/Windows menu back if a Windows update skips it (docs and Welcome tips).

### System
- **Memory protection** (systemd-oomd): an app that uses up all the memory is closed instead of the whole computer freezing.
- **`lumen doctor hardware`** (Lumen menu → Setup → Hardware report): computer model, graphics, Wi-Fi and Bluetooth chips with their drivers, boot mode, Secure Boot, firmware errors and failed apps, saved to a file to share.
- GitHub links point at the renamed account; the ISO build retries a package mirror that drops the connection.
- Small fixes: cancelling the Extras or theme menu no longer exits with an error; the key bindings page is regenerated and checked by the tests.

Existing installs get the apps, memory protection and fixes with `lumen update`.
