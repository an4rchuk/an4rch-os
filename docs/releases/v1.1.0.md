### Lumen OS is now an4rch OS
- **New name everywhere you see it**: the boot menu, installer, welcome tour, About, the console greeting, `fastfetch` and the system's release information. A placeholder circled-A logo stands in until the final artwork.
- **The command is now `anarch`**: `anarch update`, `anarch doctor`, `anarch theme`, … and every `lumen-*` command is now `anarch-*` (`anarch-theme`, `anarch-wallpaper`, …). The `lumen` names are obsolete: they only forward to the new ones (and say so in a terminal), and updating rewrites your own config files to the new names, keeping the originals in `~/.local/state/lumen/before-anarch/`.
- The signature theme is now called **an4rch** (same colours); picking `lumen` still works.
- The ISO is now `an4rch-os-<date>-x86_64.iso`.
- The project's home is moving to github.com/an4rchuk/an4rch-os; updates try it first and fall back to the old address.

### The anarchism theme pack: `anarch anarch`
- **Twelve new themes**, black with one colour each, one per school of anarchism: Anarcho-communism, Anarcho-syndicalism, Mutualism, Individualist, Anarcho-capitalism, Green anarchism, Anarcho-primitivism, Anarcha-feminism, Anarcho-pacifism, Queer anarchism, Insurrectionary and Without adjectives.
- `anarch anarch` adds them all, `anarch theme get ancom` adds one, `anarch theme packs` lists packs and `anarch theme drop anarchism` removes them.
- Buttons in a dark-accent theme (red, purple, grey) get light text so they stay readable.

### Nine wallpapers per theme
- Every theme (bundled or from a pack) now gets **five long, smooth gradient wallpapers** (*sweep* corner to corner, *glow* from a corner, *horizon*, *rise* and *mesh*) as well as the four abstract ones. Colours are blended in linear light along a smooth curve, so there are no visible bands where they meet.
- A theme can set its own gradient CSS-style (`gradient = #0b0b0b 0%, … #c8102e 100%`); the anarchism themes use theirs.
- Wallpapers are painted the first time you use a theme, at your screen's resolution, so installing is quicker.

Existing installs get all of this with `anarch update` (or `lumen update`).

### Privacy, safety and accessibility
Things other systems need add-ons for, built in (all under **Privacy and safety** in the an4rch menu; see the manual's new chapter):
- **The panic key, ⊞ + Shift + Esc**: locks the screen on an empty workspace, closes your vaults, mutes the mic and speakers, pauses media and wipes the clipboard, in one press.
- **`anarch privacy`**: a made-up hardware address on every network, encrypted DNS (Quad9, Mullvad or Cloudflare) and blocking of tens of thousands of ad, tracker and malware sites for every app. ⊞ + Alt + P.
- **`anarch vault`**: encrypted folders that open with a password and close themselves when unused.
- **`anarch sandbox`**: run an app (or a browser) that can't see your files and forgets everything it saved; `--offline` cuts its internet too.
- **`anarch scrub`**: removes hidden data (where a photo was taken, a document's author) from files; also a right-click in Files.
- **`anarch carry`**: your whole setup and app list in one file, to bring to another computer.
- **`anarch health`**: drives, filesystem, space, battery, services and temperatures in one report. Drive monitoring, a monthly btrfs scrub and a daily check are now on by default.
- **`anarch focus`**: 25 minutes without notifications, with a countdown in the top bar (⊞ + Ctrl + F).
- **`anarch a11y`**: screen reader (⊞ + Alt + R), bigger text and cursor, no animations, and a new **High contrast** theme.
- A camera-in-use indicator joins the microphone and screen-sharing ones in the top bar.

### Borrowed from other systems
Under **Tools** in the an4rch menu (see the manual's new chapter):
- **`anarch auto`** (macOS): light theme by day, dark theme and night light after sunset, from your time zone's sunrise and sunset.
- **`anarch note`** (Sticky Notes): a notes window that drops down over everything with ⊞ + Alt + K and saves as you type.
- **`anarch say`** (macOS Speak Selection): select text, press ⊞ + Alt + S, and it's read aloud.
- **`anarch share`** (Android Quick Share): a QR code your phone scans to download files, join the Wi-Fi or open a link. No app needed.
- **`anarch screentime`** (Screen Time / Digital Wellbeing): time per app, today and this week, with daily limits.
- **`anarch tidy`** (Storage Sense): frees disk space safely.
- **`anarch battery limit 80`** (optimised charging): stop charging at 80% so the battery lasts longer.
- **`anarch reset`** (ChromeOS Powerwash): the desktop back as it was after installing, keeping files and apps.

### More choices when installing
- **Desktop or Server.** The server edition has no desktop: the system, SSH (the firewall allows it, nothing else), and an4rch's command-line tools (`anarch update`, `anarch doctor`, snapshots…). For old computers and home servers.
- **Kernel:** latest (default), long-term support, zen (tuned for desktops and gaming) or hardened (extra security). A second kernel is always in the boot menu, and `anarch tune kernel zen|hardened|lts|linux` adds more later.
- **Shell:** zsh (default), bash or fish, each with an4rch's prompt, aliases and tools.
- **Extra apps:** tick apps from the App Store's list while installing (repositories first, then the AUR, then Flathub).
- **Use partitions I've made myself** (advanced): choose the partition for an4rch, the EFI partition (its other boot files are kept unless you ask to format it) and, if the EFI partition is small, a boot partition for the kernels. In the graphical installer a button opens the partition editor; the text installer offers cfdisk.
- The text installer's banner now says AN4RCH.
