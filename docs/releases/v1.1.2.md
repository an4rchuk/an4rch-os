### Fixes from a day of testing on 144 virtual machines
Every change in this release was found by installing An4rch OS on test machines (low-spec and high-spec, NVIDIA, dual boot, encrypted, offline, BIOS, French keyboards, servers) and using it the way a person would. Each fix was retested on fresh machines before release.

- **Notifications work again.** After the rename to An4rch, pop-up notifications (volume, screenshots, reminders, errors) stopped appearing.
- **The live USB starts its desktop reliably** and shuts down quickly.
- **Apps ticked in the installer are always installed.** Apps that can't be added during installation (some come from the AUR or Flathub) now install by themselves after the first start, as soon as there is internet. If one still won't install, it is tried again on the next two starts.
- **Installing with an AUR app ticked** no longer stops at the very end.
- **The install carries on if the AUR is down.** yay (the AUR helper) is optional: if aur.archlinux.org doesn't answer, An4rch installs without it and says how to add it later, instead of leaving you at a console.
- **Backups work on computers installed without internet.** restic, the backup tool, is now installed by default and carried on the USB stick. Commands that need to download something now say so straight away when there is no internet, instead of hanging.
- **Restoring a deleted file** from a backup works.
- **`anarch update` on installs from the USB stick** no longer thinks you are offline when it can't reach GitHub.
- **Phones find the computer** in KDE Connect (`anarch phone`): the firewall now lets them through.
- **Widgets** no longer stop the top bar.
- **Older installs get the new login screen** when they update, whatever the wording of their old greeting.
- The USB stick no longer carries a login for the build server.

Existing installs get all of this with `anarch update`.
