### Quick panels under the top bar
- **Clicking Wi-Fi, Bluetooth, the battery or the power icon now drops down a panel under the top bar** (like the sound panel, GNOME and KDE), instead of a menu in the middle of the screen.
- **Networks**: Wi-Fi and airplane mode switches, a hotspot button (shows the name and password to join), search, the connected network with its **live download and upload speed** and a Disconnect button, and the networks nearby with Connect (a password box opens right there; school/work networks open the full Wi-Fi menu).
- **Bluetooth**: on/off, connected devices (with battery level), your devices to connect or forget, and devices nearby to pair.
- **Power**: battery level and time left, power mode (saver / balanced / performance), screen brightness, and Lock, Sleep, Log out, Restart, Shut down (restart, shut down and log out ask for a second click).
- Right-clicking Wi-Fi or Bluetooth still opens the full menus.

### Fixes from a real laptop
- **USB sticks keep working after an update.** When an update replaced the kernel, exFAT/NTFS USB sticks wouldn't open ("not configured in kernel") until a restart. The running kernel's drivers are now kept until you restart. Tools for exFAT, NTFS and FAT drives are installed too.
- **Installing on a slow connection** no longer leaves the new system without download mirrors (the mirror test times out sooner, and Arch's worldwide mirrors are used when none answer).

### Updates
- **`lumen update` works again.** Installs from older USB sticks pointed at an address that no longer exists, so updating asked for a GitHub username and password (and failed). Lumen now always uses the right address, never asks for a login, and updates to the newest release (the same code as the ISOs). If you changed any of Lumen's own files, the changes are kept aside (`git stash list` in `~/.local/share/lumen`) instead of blocking the update.
- "Already up to date" now shows the release you're on (e.g. v1.0.9) instead of an internal number.

### Smaller ISO
- The live system leaves out manuals, help pages and translations other than English, and is compressed harder (without slowing down starting from the USB stick). What gets installed is unchanged: installs still get the full packages, manuals and translations included.

### Everything from v1.0.8
- The taskbar no longer disappears a few minutes after logging in; the top bar and taskbar come back by themselves if they ever stop.
- Installs with no internet at all; small free space next to Windows is handled; Chromium, Brave and Chrome run as native Wayland apps.

**Installed from an older ISO?** Updating needs a one-time fix: open a terminal and run
`cd ~/.local/share/lumen && git remote set-url origin https://github.com/an4rchuk/lumen-os.git && git fetch --tags origin && git stash; git checkout --detach v1.0.9 && lumen update`
— after that, `lumen update` keeps you current.
